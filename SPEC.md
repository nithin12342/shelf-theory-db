## SPEC details (acceptance = gate)

- SPEC-007: 1M 0-cells + 200k 4-cells; mem <1.5× raw; boundary lookup sub-15 ns. E2E: `tests/e2e/phase1_bcsf/`. Host qualification (2026-10-08): gate is median-of-11 steady-state true-fetch; marginal on 12 MB laptop LLC (i7-1165G7, hot set ~11.2 MB) — ~50% process PASS, excursions to ~30ns worst-round recorded in evidence; target-class 32–96 MB LLC passes with headroom. Worst-round/cold-stride series is informational Phase-2 P99 input, not gated.
- SPEC-008/009: 4 writers @50k hyperedges/s + 8 readers; zero corruption/deadlock; P99 write <200 µs (staging path; periodic-seal P99 reported separately); full commit path (begin→commit, incl. snapshot copy) P99 <2 ms over 200 sampled commits. Merge-window reader throughput ≥95% of the thermally-adjacent post-merge baseline (P1 is warmup only — cool-chip turbo made cross-window comparison measure thermals; per-op P99 series reported alongside, never median). Compactor merges via `BcsfBuilder::extend_from_reader`/`extend_range` bulk slice copies (32k-cell chunks with inter-chunk yields) with offset shifts + tombstone-block skips, pinned to a compaction core, so merges never evict reader L3 lines. WAL: header-word (valid_len + CRC) + group-commit buffering + pre-allocation; replay exact, short-file truncation semantics, garbage-past-valid ignored. Phase-2 memory footprint reported (star/live/WAL estimate ~23 MB peak) — informational, gated by Phase 6. Adversarial suite `tests/e2e/phase2_adv/` (A1 remap identity, A2 delete×merge races, A3 isolation, A4 WAL bit-flips, A5 txn matrix, A6 shadow-model fuzz, A7 prune churn, A8 degenerates) — all PASS, exit-gated. - SPEC-057: von Neumann physical-limit study. The probe (`crates/sheaf-engine/src/bin/physical_limits_probe.rs`) must (a) measure this host's memory-hierarchy latency ladder (L1/L2/L3/DRAM), read bandwidth, compute rate, and NVMe latency/throughput, (b) derive the physical floors from published constants (Landauer, Si signal flight, DDR4-3200 CAS floor, PCIe 4.0 x4 bus ceiling, HDD rotational latency, magnetic grain size) and print them side by side with the measurements, (c) decompose random-access latency into DRAM-access vs page-walk components, (d) measure the machine balance (roofline ridge point) IN THE SAME WINDOW as the bandwidth it is divided by, (e) assert 6 physics-invariant ordering gates (L1<L2<L3<DRAM; DRAM>L3; DRAM>datasheet CAS floor; fsync>>buffered write; read BW >>0 and >5% of bus peak; DRAM>L1) plus 2 clock cross-checks (8-add vs 4-add chain ratio = 2.0; 4x imul vs 4-add chain ratio = 3.0, which validates the absolute cycle count), (f) measure the REAL database scan kernel against the memory ceiling IN THE SAME WINDOW (no cross-run comparison), report the utilization per thread count, isolate the cause of any gap by a controlled experiment, and assert that the kernel never exceeds the ceiling and that the two kernel variants agree on the aggregate, and (g) compute the remaining fundamental and storage ceilings (Amdahl parallel speedup fitted to this host's OWN measured thread scaling, DRAM refresh overhead and cell-level traffic, cosmic-ray soft error rate, the Margolus-Levitin quantum speed limit, the Bekenstein information bound, the address-space ceiling, and NAND program/erase endurance) from published constants, with a gate on each that asserts the physics is self-consistent, and (h) MEASURE the read and write amplification of the shelf representation against the theoretical floor of 1.0, on the same workload in every arm, with the fiber read compared against every base read and the shadow merge compared against the copy merge.
