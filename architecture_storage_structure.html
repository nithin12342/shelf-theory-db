Native Geometric Shape: The Cellular Sheaf Complex

In mathematics, a cellular sheaf ƒ over a graded cell complex χ assigns: (1) a base cell to every entity, (2) a vector stalk space ƒ(σ) standing vertically over each cell σ, and (3) linear restriction morphisms ρσ⊴τ transporting stalk vectors along boundary incidences.

Mathematical Definition: A 0-cochain (section) assigns vector xv to each vertex. The coboundary operator δ measures inconsistency across every incident edge: (δx)e = W1,e x1 - W0,e x0. The Dirichlet energy is E(x) = ∑ ∥(δx)e∥². When E(x) = 0, the section is harmonic.

Native Geometric Shape: The Topological Fiber Bundle (E, B, π, F)

A fiber bundle (E, B, π, F) consists of a base space B, a total space E, a continuous projection π: E → B, and a standard fiber space F. In Sheaf-DB, B is the pre-aggregated query group key space, F is the materialized result stalk, and π projects complex cells into instant answers.

Why the Fiber Bundle Wins: A query for a pre-aggregated group touches only the vertical fiber Fb*. It reads exactly 208 bytes with 13.0 read amplification. It avoids scanning the underlying base space entirely.

Structure-of-Arrays (SoA) Primary Layout

The memory representation uses Structure-of-Arrays (SoA) rather than Array-of-Structures (AoS). Contiguous columns enable AVX-256/AVX-512 vector arithmetic with unit stride memory access.

Shadow Merge & Paging vs Copy Merge

The compactor uses shadow paging to reach a write amplification of 1.0002. Instead of copying the full base on every merge, it appends only the delta.

Standard Copy Merge (Write Amp = 2.0000)

Traditional LSM merge rewrites the whole run. 200,000 base + 1,000 delta = 201,000 cells rewritten (8.0 ms).

Sheaf-DB Shadow Merge (Write Amp = 1.0002)

Base is untouched. Reader holds a Chain referencing the base plus delta. Compaction completes in 1.0 ms.
